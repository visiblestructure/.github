# VisibleStructure

We are exploring open-source tools for making software interfaces easier for AI
agents to understand, discover, operate, compose, and evaluate.

## What we are working on

**Agent Interface** is currently in planning. Its initial direction is an
evidence-backed compiler and quality gate for agent-facing interfaces across
instructions, CLI commands, tools, APIs, product state, guardrails, and recovery
paths.

The first milestone is deliberately narrow: compile a pinned public repository
revision into a provenance-aware intermediate representation, then generate
useful execution views and high-confidence static findings.

More project repositories and an official website will be linked here after
their boundaries and public addresses are confirmed.
